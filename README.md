# Bionic Chat — Streamlit-интерфейс к локальной LLM

Веб-приложение чата с моделью, развернутой на сервере **Bionic**
(OpenAI-совместимый REST API). Поддерживает стриминг ответов,
историю диалога и настройку параметров модели через боковую панель.

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

```bash
streamlit run app.py
```

## Настройка подключения

Значения можно задать через переменные окружения или прямо в боковой панели UI:

| Переменная        | По умолчанию               | Описание                          |
|-------------------|----------------------------|-----------------------------------|
| `BIONIC_BASE_URL` | `http://localhost:8000/v1` | Base URL OpenAI-совместимого API  |
| `BIONIC_API_KEY`  | `not-needed`               | API-ключ                          |
| `BIONIC_MODEL`    | `bionic`                   | Имя модели                        |

Пример:

```bash
BIONIC_BASE_URL=http://bionic-server:8000/v1 BIONIC_MODEL=gpt-proxy streamlit run app.py
```

## Возможности

- 🔄 **Стриминг** ответов (частичный текст обновляется в реальном времени)
- 🧠 **История диалога** в рамках сессии + усечение контекстного окна
- ⚙️ **Боковая панель**: Base URL / API Key / модель, temperature, top-p,
  max tokens, системный промпт, тумблер стриминга
- 🔌 Кнопка «Проверить соединение» (запрос `/models`)
- 🧹 Очистка истории и отмена последнего шага
- ✅ Валидация настроек через `pydantic` (`config.py`)

## Структура проекта

```
app.py             # Streamlit UI, история, стриминг
bionic_client.py   # Клиент openai>=1.0 для Bionic API
config.py          # Pydantic-модели настроек и параметров генерации
requirements.txt
```
